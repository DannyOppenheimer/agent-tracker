AI Agent Tracker for Windows

Extract the entire ZIP to a folder you can keep. Double-click agent-tracker.exe
to open the dashboard. You can also run .\agent-tracker.exe from PowerShell.
Add the extracted agent-tracker folder to your user PATH to use the
agent-tracker command from any directory in new terminals.

The dashboard shows local Claude Code, Codex, and Antigravity chats when
available. Usage tiles appear as the agents report data. If Gemini has a
separate usage page, Right Arrow opens it and Left Arrow returns. Use Up/Down
or the mouse wheel to scroll and Ctrl+C to exit.

Use your existing agent installations and sign in normally. On launch, the
tracker configures usage collection for detected Claude and Antigravity
installations with no status line configured. Reopen the affected agent to
start collecting. If you already have a custom status line, it is preserved.
For custom setups, append --capture-claude-usage or --capture-antigravity-usage
to the full path to agent-tracker.exe and pass the status-line JSON on stdin.
Codex account usage requires the Codex CLI and an authenticated account.

Windows 10/11 with the architecture named on the ZIP is the target.
Keep the bundled _internal folder beside the executable. Python is bundled.
